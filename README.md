# Docker Compose master directory for my personal homelab stacks.
Each subfolder contains a separate service (Scrutiny, Grafana, etc.) with its own compose file and config.
Use `docker compose up -d` inside any folder to launch that service.

## disclaimer
in the unlikely event anyone else ever uses any of this
- **PAY ATTENTION** many of these compose files will be used in my homelab and for testing
- They are therefore often **NOT PRODUCTION READY** and should broadly be treated as such.
